# M1-2 · 나를 아는 콘텐츠 제작 비서

기존 콘텐츠 원고, 명시적으로 확인한 제작 취향, 계정 시계열 데이터를 바탕으로 다음 콘텐츠를 기획하고 카드뉴스 원고와 퀴즈 초안을 만드는 개인화 AI 비서입니다.

단순 지표 설명을 넘어 **기획 → 초안 → 사용자 수정 → 다음 제작에 반영**하는 흐름을 목표로 합니다.

## 현재 상태

저장소와 설계 문서를 준비한 단계입니다. 애플리케이션, 실제 API 연동, 배포는 아직 구현하지 않았습니다.

## 기술 스택 및 배포 계획

- 프론트엔드: HTML / CSS / JavaScript, Vercel
- 백엔드: Python 3.10+, FastAPI, Pydantic, Render
- 저장소 및 인증: Firebase Firestore, Firebase Authentication
- 생성 AI: OpenAI API (모델은 환경 변수로 교체)
- 참고 데이터: [M1-1](https://github.com/gaori2952/M1-1)의 계정 시계열 데이터

## 구현할 기능

1. Google 로그인과 사용자별 데이터 접근 통제
2. 시계열 데이터 CRUD 및 서버에서 계산하는 통계 요약
3. 기존 콘텐츠 검색과 확인된 선호를 활용한 맞춤 채팅
4. 후속 주제, 카드뉴스 원고, 퀴즈 초안 생성
5. 대화 자동 저장·불러오기와 수정 피드백 기록
6. Render / Vercel 배포, Swagger 문서 및 제출 화면 정리

자세한 역할과 데이터 흐름은 [아키텍처](docs/architecture.md)를 참고하세요.

## 환경 변수 계획

| 위치 | 변수 | 역할 |
| --- | --- | --- |
| 백엔드 | OPENAI_API_KEY | OpenAI 서버 인증 |
| 백엔드 | OPENAI_MODEL | 생성 모델 선택 |
| 백엔드 | FIREBASE_SERVICE_ACCOUNT_JSON | Firestore 및 토큰 검증용 서비스 계정 |
| 백엔드 | ALLOWED_ORIGINS | 허용하는 프론트엔드 주소 |
| 백엔드 | ALLOWED_USER_UIDS | 초기 개인 서비스 접근 허용 UID |
| 프론트 빌드 | API_BASE_URL | 공개되는 백엔드 주소 |
| 프론트 빌드 | FIREBASE_WEB_CONFIG | Firebase 웹 클라이언트 설정 |

바닐라 브라우저 코드가 배포 서버의 환경 변수를 직접 읽을 수 없으므로, 빌드 시 공개 설정 파일을 생성할 예정입니다. 서비스 계정과 OpenAI 키는 백엔드에만 둡니다.

## 로컬 실행 및 배포

실행 명령과 의존성 파일은 구현 후 검증해서 추가합니다.

- 프론트엔드 URL: 미배포
- 백엔드 API / Swagger URL: 미배포
- 제출 스크린샷: 구현 및 실제 동작 확인 후 추가

## 공개 저장소 관리

개인 대화 원문, 비공개 콘텐츠 원고, 실제 개인 데이터, 서비스 계정 키는 커밋하지 않습니다.
공개 예시 데이터가 필요한 경우 합성 데이터임을 명시합니다.
