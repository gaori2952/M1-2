`backend/tests/preview.py`는 합성 시계열 120개와 모의 생성 결과를 사용하는 로컬 테스트 서버입니다. Render 시작 명령은 `app.main:app`이며 테스트 서버를 사용하지 않습니다.

스크린샷은 이 합성 테스트 환경의 화면입니다. 실제 개인 데이터/GPT 응답이나 배포 증빙으로 제출하면 안 됩니다.

## 구현 범위와 제한

- 단일 개인 사용자부터 시작하며 ALLOWED_USER_UIDS로 명시적으로 허용한다.
- 서버가 컬렉션을 소유자별 조회 후 메모리에서 기간·검색을 처리한다. 10,000문서를 넘으면 잘못된 부분 결과 대신 오류를 반환한다. 대규모 사용 전 서버 쿼리와 페이지네이션이 필요하다.

- 수식 편집은 LaTeX 원문을 보존한다. 초기 화면은 원문 표기이며 수식 조판 렌더링은 후속 개선이다.
- 일반 선호는 사용자가 직접 확인 후 저장한다. 피드백은 자동으로 영구 선호로 승격하지 않는다.

- 예외 브라우저 E2E: 위장 형식 거부, 로컬 이미지 유실·해시 불일치·동일 파일 복구, 로그아웃 시 확대 이미지 제거, 완료 응답 유실 후 추가 POST 없이 복구, 모델 문자열 XSS 비실행, 늦은 응답 중 계정 변경, IndexedDB 쓰기 실패 시 검토 미전송을 확인했습니다.
- 기존 회귀: flow, durability, editor, editor-regressions 모두 통과했습니다. 기존 시계열 CRUD·요약·채팅·기록·원고 편집·PNG ZIP 동작을 유지합니다.
- E2E는 메모리 저장소·목 인증·목 모델입니다. Firestore 실서비스 E2E나 AI 정확도 평가와 같지 않습니다. 공개 스크린샷은 합성 카드와 목 모델 결과만 포함합니다.

### 현재 설정으로 수행한 실제 이미지 호출

현재 로컬 설정의 Anthropic 호환 게이트웨이와 `claude-sonnet-4`에 합성 PNG 2장만 전달했습니다. 사용자 자료·기존 대화·Firestore는 사용하지 않았습니다. 모델은 이미지의 `CARD 01`, `CARD 07`과 `E = F/q`, `E = q/F`를 구분했고, 두 번째 식의 분자·분모 반전과 장 사이 모순을 오류로 지적했습니다. 구조화 응답도 정상적으로 파싱했습니다.

이는 2장에 대한 전송·판독 가능성 확인입니다. 한국어 소형 글자, 복잡한 수식·도식, 모든 과학 주제의 정확성을 보증하지 않습니다. OpenAI 경로는 실제 SDK 전송 테스트를 통과했으나 이 기능의 실제 OpenAI 호출은 수행하지 않았습니다. 과제의 GPT 사용 요건 충족에는 별도 실제 호출 확인이 필요합니다.

### 보관·운영 한계

이미지 원본·검토용 파일은 같은 브라우저 IndexedDB에만 보관합니다. 다른 기기에서는 같은 파일을 다시 선택해야 합니다. 서버는 해시·파일명·검토 기준·결과·이력만 저장합니다. 전체 검토는 최대 10장, 원본 10MB/장, 검토용 2,400px·1MB/장, 본문 16MB 제한입니다. 원본은 4천만 화소를 넘으면 먼저 줄여야 합니다. 단일 장 교체는 다른 장 결과를 유지하되 연결 검토는 갱신 필요로 표시합니다.
